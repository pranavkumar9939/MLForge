# MLForge — Frontend

React + Vite frontend for MLForge. See the [repository root README](../README.md) for full project documentation, architecture, and Docker instructions.

## Quick start

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build to `dist/`
- `npm run lint` — ESLint
- `npm test` — run the vitest suite
